# Changelog

## 0.1.0 — 2026-11-20

- Initial release.
- Per-project Discord webhook channels with selectable work package and wiki
  events.
- Discord embeds for created, updated, status-changed, assignee-changed,
  commented and deleted work packages.
- Discord embeds for created, updated and deleted wiki pages.
- Background delivery with retries, delivery logs and a test-message action.
- Global admin settings and an overview of all project channels.
